VoiceTyper 安装说明

1. 将 VoiceTyper.app 拖到 Applications。
2. 从"应用程序"中打开 VoiceTyper，不要直接在 DMG 中运行。
3. 如果首次打开被 macOS 拦截，请到"系统设置 > 隐私与安全性"点击"仍要打开"。
4. 进入应用后会自动打开"使用引导"，跟着四步走完即可：
   欢迎 -> 三项系统权限（麦克风、辅助功能、输入监控）-> 语音模型下载 -> 试一试。
5. 授权的同时，应用已在后台自动下载一次语音识别模型（SenseVoice-Small，约 230MB），
   不需要等待授权完成。下载只需一次，完成后完全离线可用。
6. 引导最后一步会让你在窗口里真正试一次听写。请务必做完这一步：
   权限全绿并不等于能用，只有这一步能验证"热键 -> 麦克风 -> 识别 -> 插入"整条链路。
7. 之后就可以按住热键（默认 Fn）说话，松开即可识别并输入文字。
   录音中和识别中都可以按 Esc 取消。

提示：
- 首次安全放行通常只需要一次。
- 如果按住 Fn 说话时系统弹出表情面板或切走了输入法，请把
  "系统设置 > 键盘 > 按下🌐键"改为"不执行任何操作"（引导页有直达按钮）。
- 本应用为 ad-hoc 签名，更新到新版本后三项权限可能需要重新授权一次。
- 本应用要求 Apple Silicon（M 系列芯片）与 macOS 14 及以上。
- 若之前安装过旧版 VoiceTyper（分体式客户端），建议卸载它并停止其配套的
  Python 服务端，改用本应用即可，两者不建议同时运行。
