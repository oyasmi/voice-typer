# VoiceTyper for macOS

**简体中文** · [English](README.en.md)

[← 项目主页](../README.md) · [下载安装包](https://github.com/oyasmi/voice-typer/releases) · [更新日志](CHANGELOG.md) · [开发说明](DEVELOPMENT.md)

VoiceTyper 是一款轻量菜单栏语音输入应用：在任何窗口里按住 <kbd>Fn</kbd> 说话，松开后文字就会直接写到光标处。语音识别完全在你的 Mac 本机运行，录音绝不上传。

## 安装与系统要求

| 项目 | 要求 |
| --- | --- |
| **芯片** | Apple Silicon（M 系列芯片），不支持 Intel Mac |
| **系统** | macOS 14 Sonoma 或更高版本 |
| **磁盘空间** | 约 300 MB（含应用本体与首次自动下载的语音模型） |
| **网络需求** | 仅首次下载语音模型时需要联网，之后可完全离线使用 |

### 安装步骤

1. 前往 [Releases](https://github.com/oyasmi/voice-typer/releases) 下载最新的 `VoiceTyper-<版本>-macOS-arm64.dmg`。
2. 双击打开 DMG，将 `VoiceTyper.app` 拖入「应用程序」文件夹。
3. 从「应用程序」启动 VoiceTyper。

> [!NOTE]
> 安装包目前尚未经过 Apple 公证。首次打开若提示「无法验证开发者」，请打开 **系统设置 → 隐私与安全性**，滑到底部点击 **仍要打开** 即可（只需放行这一次，不影响功能与安全性）。

## 首次启动

第一次运行会弹出四步引导：**欢迎 → 权限 → 语音模型 → 试一试**。

### 1. 授予三项系统权限

三项权限缺一不可，引导界面会逐项提供一键跳转按钮：

| 权限 | 用途 | 未开启时的表现 |
| --- | --- | --- |
| **麦克风** | 采集你的语音 | 按下热键无法开始录音 |
| **输入监控** | 在其他应用处于前台时响应全局热键 | 按下热键没有任何反应 |
| **辅助功能** | 将识别好的文字写入当前光标处，并拦截取消键 | 浮窗识别正常，但文字写不进目标窗口 |

### 2. 自动准备语音模型

在你授权的同时，约 240 MB 的语音模型会在后台自动下载并校验完整性。下载支持断点续传与失败自动重试；若本机之前运行过分体式服务端，已有的模型缓存会自动复用。

### 3. 完成一次真实试听写

引导的最后一步会让你在窗口内亲自试一次「按住说话、松开出字」。只有这一步跑通，才代表热键、麦克风、模型识别与文字输入整条链路全部就绪；若哪一环异常，引导会直接指出原因。日后随时可从菜单栏点击「使用引导…」重新打开。

## 日常使用

1. 把光标点在需要输入文字的位置。
2. 按住 <kbd>Fn</kbd>，**等屏幕出现浮窗后**开口说话。浮窗会实时展示识别结果，并随着后文语境自动回头修正前面的字词。
3. 松开 <kbd>Fn</kbd>，带好标点的最终文字直接写入当前应用。

### 顺手的日常细节

- **随时取消**：录音中或识别中按 <kbd>Esc</kbd> 立即作废，不写入任何文字，且不会误关前台弹窗或退出全屏。
- **找回历史文字**：菜单栏提供「复制上一次结果」与「最近结果」（保留最近 10 条，包含中途取消、焦点切换或未能自动写入的内容）。点一下即可复制，仅保存在内存中，退出应用即清空。
- **长段口述**：不想一直按着按键时，可在设置中将触发方式改为「按一次开始、再按一次结束」。单次最长支持 120 秒，最后 15 秒显示倒计时；短于 0.3 秒的轻触自动按误触忽略；松键后会自动补录约 150ms，防止吞掉最后一个字。
- **中英混说与数字排版**：无需切换语言，中英文混说自动在词间加空格（「我用 Python 写代码」），口述数字自动整理为阿拉伯数字。
- **蓝牙耳机不降音质**：默认开启麦克风「自动」策略——佩戴蓝牙耳机时自动改用 Mac 内置麦克风收音，避免耳机切入通话模式导致音乐中断、音质骤降。
- **密码框自动保护**：光标在密码框中时不会启动听写；若录音中途焦点移入密码框，结果只会复制到剪贴板而不会直接写入。
- **菜单栏快捷操作**：点击菜单栏图标即可快速切换识别语言、麦克风策略、智能校对，或临时暂停听写。

## 设置

所有配置均可在图形界面中完成，无需手动编辑配置文件：

| 设置页 | 包含选项 |
| --- | --- |
| **权限** | 麦克风、输入监控、辅助功能三项权限的实时状态与跳转入口 |
| **识别** | 模型状态与下载管理、识别语言（自动 / 中 / 英 / 粤 / 日 / 韩）、内存驻留策略、智能校对 |
| **词汇** | 自定义词汇表（人名、产品名、专业术语）与识别偏向强度 |
| **通用** | 听写热键、触发方式（按住 / 按一下切换）、麦克风选择、浮窗位置与透明度、开机自启、界面语言 |

几个值得留意的选项：

- **热键选择**：支持 <kbd>Fn</kbd>、组合键（如 <kbd>⌥</kbd><kbd>Space</kbd>），也支持**单独一个修饰键**（右 <kbd>⌘</kbd> / 右 <kbd>⌥</kbd> / 左 <kbd>⌥</kbd> / 右 <kbd>⌃</kbd>，非常适合没有 <kbd>Fn</kbd> 键的外接机械键盘）。设为单独修饰键时，按住它再按其他键依然是正常快捷键，不会误触发听写。
- **内存策略**：默认启动时预加载模型并常驻内存（约 500 MB），换取按下热键零延迟响应。如果平时较少使用，可关闭启动预加载，或设置空闲一段时间后自动释放——下次按热键时会边录音边加载模型。
- **界面语言**：支持简体中文与 English（重启应用生效），与识别语言互不影响。

### 自定义词汇

经常被认错的人名、产品名、项目代号或行业术语，可以添加到「设置 → 词汇」中（最多 200 条，全程在本机运行、不联网）：

- **写法**：期望输出的正确写法，例如 `VoiceTyper`、`Claude`、`张三丰`。
- **听起来像**（可选）：平时常被误认成的同音字词，例如给 `Claude` 填 `克劳德`。仅大小写、空格或连字符不同的变体（如 `voice typer`、`Voice-Typer`）无需手动填写，系统会自动统一为你设定的写法。
- **识别偏向**：提供「关 / 轻 / 标准 / 强」四档（默认「标准」）。档位越高越容易命中词表，但也更可能把读音相近的普通词往词表上靠；读音明显不同的词不会被硬改。如果偶遇误改，调低一档即可。
- **从最近结果快速添加**：发现刚说的一句里有词被认错时，点「从最近结果添加…」，直接框选错字并填上正确写法就能入库。
- **状态提示**：`✓` 表示该词同时参与识别偏向与文本替换；`⚠` 表示单字或单个英文片段，仅做文本替换以防误伤日常用词。

开启智能校对时，自定义词汇表也会自动附带给校对模型参考。

### 智能校对（可选，默认关闭）

可接入任意兼容 OpenAI 接口的服务（包括 Ollama、LM Studio 等本机离线模型），进一步修正同音错字、口误重复并顺滑标点：

- 开启后**只发送识别出的文字**到你填写的服务地址，音频永远不会发出；API Key 加密保存在 macOS 系统钥匙串中。
- 等待校对期间，再按一次听写热键即可立即跳过校对、直接上屏识别原文。
- 若遇到网络超时或服务报错，会自动回退并写入识别原文，浮窗会简要提示原因。

## 隐私

- 录音仅在内存中实时处理，不落盘、不上传。
- 模型下载完成后即可彻底断网使用，无需登录账号，无使用次数限制。
- 系统日志不记录识别文本与自定义词汇；菜单栏「最近结果」仅存于内存，退出应用即清除。

## 常见问题

### 按 <kbd>Fn</kbd> 时会弹出表情符号面板或切换输入法？

前往 **系统设置 → 键盘**，将「按下 🌐 键以」改为 **不执行任何操作**。首次引导页和「设置 → 通用」也会自动检测这一冲突并提供跳转按钮；或者你也可以在设置里换用其他热键（如右 <kbd>⌘</kbd> 或右 <kbd>⌥</kbd>）。

### 按下热键完全没反应？

1. 打开「设置 → 权限」检查 **输入监控** 是否已开启。
2. **刚覆盖更新过应用版本？** 由于当前安装包尚未进行 Apple 公证，macOS 可能会在更新后认为旧权限签名失效：请前往「系统设置 → 隐私与安全性 → 输入监控（及辅助功能）」，选中 VoiceTyper 点 `-` 号移除，再点 `+` 号重新添加，最后完全退出并重启 VoiceTyper。
3. 若终端等应用开启了「安全键盘输入」，或焦点正处于密码框，macOS 系统会临时屏蔽全局组合键热键，菜单栏会给出相应提示。

### 浮窗识别出了文字，但没有写进当前窗口？

先检查「设置 → 权限」中的 **辅助功能** 权限（刚更新过版本同样建议移除后重添一次）。少数应用本身拒绝外部模拟输入，此时文字已保存在剪贴板和菜单栏「最近结果」里，按 <kbd>⌘</kbd><kbd>V</kbd> 粘贴即可。

### 浮窗提示「没有识别到内容」？

录音时浮窗会显示当前正在使用的麦克风名称。请确认麦克风未被硬件静音、「系统设置 → 声音 → 输入」设备正常，且未被其他软件独占；持续收不到声音时浮窗也会主动提醒。

### 模型下载中断或失败？

确认网络可访问 ModelScope 后，在「设置 → 识别」点击重试即可从断点附近继续下载，无需从头重下。

### 可以和旧版「分体式客户端」同时安装吗？

可以共存，但两者默认热键都是 <kbd>Fn</kbd>，同时运行会争抢热键，建议只保留一个。首次安装一体化版本时，会自动继承旧版的热键与浮窗透明度配置。

### 已知限制

- 仅支持 Apple Silicon（M 系列芯片）Mac；
- 固定使用调优过的 SenseVoice-Small 模型，不支持切换其他语音模型；
- 仅支持本机离线识别，不支持连接远程识别服务器（若有 Intel Mac、多模型或远程服务端需求，请使用[客户端—服务端版本](../client-server/README.md)）。

## 卸载

1. 退出 VoiceTyper，删除「应用程序」中的 `VoiceTyper.app`。
2. 删除配置与语音模型目录：`~/Library/Application Support/VoiceTyper/`。
3. 如需清理系统授权记录，可在「系统设置 → 隐私与安全性」的麦克风、输入监控与辅助功能列表中移除 VoiceTyper。
