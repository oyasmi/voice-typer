# 更新日志

macOS 应用（`macos/`）的版本变更，按版本倒序排列，只记录用户能感知的变化。实施细节、取舍与手工验证步骤见
[`DESIGN.md`](DESIGN.md)；Windows 版见 [`windows/CHANGELOG.md`](../windows/CHANGELOG.md)，旧客户端—服务端
架构见 [`client-server/server/CHANGELOG.md`](../client-server/server/CHANGELOG.md)。

## 未发布

架构与实现审查修复（R9，见 [`DESIGN.md`](DESIGN.md) §11.6）。本轮尚未在 macOS 上编译与真机验证。

### 改进

- 松键之后不再发起预览识别，终稿不必排在一次注定被丢弃的预览后面，出字更快。
- 识别阶段只在预计要走粘贴时才备份剪贴板；文字直接写入时不再触碰剪贴板，剪贴板里有大图时也不会拖慢浮窗。
- 插入后的结果核对不再占用出字前的时间。
- 模型下载中途断网后从断点附近继续，不再整段重下。

### 修复

- 只修改智能校对的 API Key 时，新 Key 要到重启后才生效。
- 从菜单栏或设置切换麦克风后，要到重启后才生效。
- 目标应用响应较慢时，同一段文字可能被输入两次；现在没有得到确认时只复制到剪贴板并说明。
- 「没有识别到内容」提示一出现就消失。
- 取消一段听写后立刻开始下一段，偶尔会导致新录音无法用松键结束。
- 配置文件损坏时应用无法使用；现在会另存原文件、以默认设置启动并说明。

## 3.5.2 — 2026-10-18

用户体验打磨（R8，规格见 [`docs/UX_R8_SPEC.md`](docs/UX_R8_SPEC.md)）。单元测试全部通过；涉及热键、剪贴板、
麦克风、浮窗与辅助功能的行为**尚未在真机验证**，逐项手工步骤见 [`DESIGN.md`](DESIGN.md) §11.5。

### 新增

- **最近结果**：菜单栏新增「复制上一次结果」与「最近结果」（最多 10 条，只在内存中，退出即清，可手动清空）。
  取消、焦点变化、插入失败时已识别出的内容都能在这里找回。
- **中英文之间自动加空格**，作用于上屏文本、预览与最近结果，与是否开启智能校对无关。
- **校对中再按热键可跳过校对**，立即上屏识别原文；校对失败时浮窗显示「已输入 · 未校对」并说明原因。
- **120 秒上限倒计时**：最后 15 秒计时变为橙色「还剩 N 秒」。
- **密码框保护**：焦点在密码框时不开始听写；录音中途焦点移到密码框则只复制、不插入。系统「安全输入」导致
  组合键热键失效时，菜单、设置与引导会说明原因。
- **菜单栏快捷切换**识别语言、麦克风（自动 / 跟随系统）与智能校对。
- **操作提示**：切换模式下提示「再按 X 结束」，按住模式前 5 次提示「Esc 取消」。
- **模型下载进度详情**（已下载 / 总量、速度、剩余时间）；下载完成且窗口都已关闭时，浮窗提示可以开始说话。
- **更新后重新授权引导**：本机签名版本更新后权限失效时，「权限」页顶部给出说明。

### 改进

- **热键与 Esc 不再「穿透」到前台应用**（需要辅助功能权限）：组合键热键不会再往前台应用多打一个字符，用来取消
  听写的 Esc 也不会同时关掉对话框或退出全屏。`Fn` 与单独修饰键的事件仍然放行。
- **预览更跟嘴**：音频采集块从 600ms 缩短到 200ms，预览改为按新音频事件驱动。
- **浮窗出现在正在输入的窗口所在的屏幕**（此前跟随鼠标）；「跟随光标」改为「跟随输入位置」，放在输入光标下方。
- **浮窗更小、更稳**：起步宽度 400pt，一行放不下时一次加宽到 600pt，一次听写中不再来回伸缩；长句预览最多
  三行，再多时整行上移（最早的一行整行消失），不再逐字往前爬；预览下方不再空出一大片，文字左对齐。
- **松键后补录约 150ms**，减少最后半个字被截掉；预览中刚变化的尾部会短暂以次级色显示。
- 长录音的识别等待时间按时长放宽，冷加载时浮窗说明「模型加载中」；识别超时会把已识别的部分复制到剪贴板。
- 剪贴板备份提前到识别阶段，缩短松键到上屏的时间；网页中的输入控件直接走粘贴。

### 修复

- 热键松开事件丢失（卡键）时会自动结束录音；锁屏 / 睡眠时丢弃进行中的录音，唤醒后自动恢复热键监听。
- 保存设置后不再丢失待恢复的原剪贴板。

## 3.5.1 — 2026-10-03

### 改进

- **重写 LLM 校对提示词**，示例从 6 组扩到 8 组：新增口误自我修正、中英文之间加空格、口语小数目转回汉字、
  口述列举转编号列表。提示词与 Windows 版、服务端共用同一份。

### 修复

- 启动后或睡眠唤醒后第一次按热键，浮窗一闪而过、什么都没录到（3.5.0 引入）。

## 3.5.0 — 2026-09-29

### 新增

- **单独修饰键热键**：右 ⌘ / 右 ⌥ / 左 ⌥ / 右 ⌃，适合没有 Fn 键的外接键盘；按住它再按别的键仍是普通快捷键。
- **蓝牙耳机自动改用内置麦克风**，避免耳机切到通话模式导致音质变差；可改为严格跟随系统默认输入。浮窗显示
  实际使用的麦克风。
- **智能校对默认关闭「深度思考」**，混合推理模型的校对明显更快；不支持该参数的服务自动改用普通请求。
- **浮窗动效**：录音结束「收声」、结果图标弹入、「校对中…」流光；开启「减少动态效果」时只做淡入淡出。
- 每次听写在日志中输出一行耗时摘要（只含数字，不含识别文本），便于排查「为什么慢」。

### 修复

- Dvorak、Colemak 等键盘布局下模拟粘贴发错快捷键。

## 3.4.0 — 2026-09-11

### 新增

- **英文界面**：设置 → 通用 → 界面语言，可选中文（默认）或 English。菜单栏、设置窗口、浮窗、首启引导与错误
  提示均已双语化，切换后重启生效。界面语言与识别语言相互独立。
- 新增英文版使用说明。

## 3.3.1 — 2026-09-11

### 改进

- 「启动时预加载模型」默认开启，「空闲卸载」默认改为「从不」：按热键始终零等待。内存紧张时可在设置里改回。

### 修复

- 浮窗透明度滑杆拖动无效；下限从 50% 降到 40%。
- 空闲卸载后首次按热键，模型加载期间会丢掉正在进行的听写。现在加载与录音并行完成，开头的音频不丢。

## 3.3.0 — 2026-09-08

### 修复

- 「按下 🌐 键」冲突检测读错系统设置，导致「重新检测」无效、冲突提示无法消除。识别页文案精简。
