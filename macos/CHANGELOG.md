# Changelog

macOS 一体化 App（`macos/`）的版本变更记录。3.3.1 之前的版本沿革见
[`DESIGN.md`](DESIGN.md) 决策记录 D3；旧客户端—服务端架构的变更见
[`client-server/server/CHANGELOG.md`](../client-server/server/CHANGELOG.md)。

## 3.5.0

R7 批次。单元测试全部通过；涉及热键、麦克风、剪贴板与浮窗观感的部分
**尚未在真机验证**，见 [`DESIGN.md`](DESIGN.md) §11.4。

### 新增

- **会话级耗时日志**：每次听写结束输出一行 `category == "metrics"` 摘要（只含数字与枚举，不含文本）。
- **LLM 关闭深度思考**：校对请求默认带 `thinking: {"type": "disabled"}`；服务以 400/422 拒绝时自动去掉
  字段重发一次，并按「接口地址 + 模型」缓存结果（不含 API Key）。「测试校对」总是重新探测并显示结果。
- **蓝牙耳机自动用内置麦克风**：新增配置 `audio.input_device`（`auto` / `system` / 设备 UID）与
  设置 → 通用 →「麦克风」选项；HUD 显示实际使用的设备。
- **单独修饰键热键**：右 ⌘ / 右 ⌥ / 左 ⌥ / 右 ⌃，支持按键录制与「使用右 ⌘」按钮；按住它再按别的键或点鼠标
  时作为普通快捷键，本次录音被静默丢弃。此类热键下浮窗延迟 150ms 出现。
- **浮窗动效**：录音结束的「收声」、结果图标弹入、「校对中…」流光；开启「减少动态效果」时退化为淡入淡出。

### 修复

- 模拟粘贴在 Dvorak / Colemak 等布局下发出错误快捷键（固定使用 QWERTY 的 V 键位）。

## 3.4.0

新增中英双语界面支持。中文仍是默认语言，英文是与之对等的第二语言（不是简化版提示）。

### 新增

- **界面语言可切换**：设置 → 通用 → 界面语言，中文（默认）/ English。菜单栏、主菜单、
  设置窗口三页、HUD 浮窗、首启引导四步，以及会出现在浮窗和弹窗里的错误文案都已双语化。
- 新增配置字段 `ui.interface_language`（`zh` / `en`）。与「识别」页的识别语言相互独立：
  可以用英文界面听写中文。
- 新增英文版 README（`macos/README.en.md`），与中文版顶部互相链接。

### 已知限制

- **切换语言后需要重启应用**：菜单栏、设置窗口与浮窗都是按启动时的语言构造出来的，
  设置项落盘即时生效，但全部界面文本改用新语言要等下次启动。设置页与文档均已注明。
- 日志（`os.Logger`）保持中文——它是开发者诊断通道，不属于用户界面。
  侧载模型时才会出现的模型契约诊断文案（维度不符、`tokens.json` 格式错等）同理未双语化。
- `DESIGN.md` 仍只有中文版。

### 实现说明

文案表以**中文原文为键**（`L("录音中")` / `LF("下载模型 %d%%", n)`），查不到翻译时回落中文
原文，因此漏翻最坏情况是显示中文，不会把键名泄漏到界面上。新增的 `LocalizationTests`
扫描全部源码里的 `L(...)` / `LF(...)` 调用，要求每条都有英文翻译且占位符一致——漏翻会让
测试失败，而不是等英文用户看到半个中文界面。

## 3.3.1

可用性与默认值打磨，无新功能、无破坏性变更。

### 修复

- **HUD 透明度滑杆无效**：此前滑杆只调一层黑色叠层的透明度，磨砂背景本身始终不透明，
  拖动全程看不出变化。现在透明度直接作用于整个磨砂层；滑杆下限从 50% 降至 40%。
- **模型加载期间丢掉进行中的听写**：空闲卸载后首次按热键时，模型进入加载态会被就绪
  检查判定为"未就绪覆盖进行中的听写"而终止录音、丢弃首段音频。现在加载期间保留活动
  听写态，模型加载与录音并行完成（引擎就绪后回灌缓存的待识别音频）。

### 默认值变更

- **「启动时预加载模型」默认改为开启**：首次按热键零等待。低频使用且在意 ~510MB 常驻
  内存的用户可在设置中关闭。
- **空闲卸载默认值从 10 分钟改为「从不」**：与启动预加载配套，按热键始终零等待。内存
  紧张的机器可在设置里改回定时卸载。

## 3.3.0
