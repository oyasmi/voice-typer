# 变更记录

Windows 应用（`windows/`）的版本变更，按版本倒序排列，只记录用户能感知的变化。实施细节与取舍见
[`DESIGN.md`](DESIGN.md) 对应章节，评审编号对照与遗留项见 [`docs/REVIEW_HISTORY.md`](docs/REVIEW_HISTORY.md)，
真机验证清单见 [`docs/VERIFICATION.md`](docs/VERIFICATION.md)。macOS 版见
[`macos/CHANGELOG.md`](../macos/CHANGELOG.md)。

## 未发布

3.5.1 发布后陆续合入的改动（DESIGN §15.2、§18–§26）。已在 Windows x64 真机上 `dotnet build` / `dotnet test` 全绿；
下列热键、麦克风、剪贴板、浮窗与通知相关的行为**尚未系统性真机验证**，步骤见各 DESIGN 章节。

### 新增

- **中英文之间自动加空格**（「我用 Python 写代码」），作用于上屏文本、预览与「复制上一次识别结果」，与是否开启
  智能纠错无关；规则与 macOS 共用同一份测试夹具。
- **右 Alt 可单独作为热键**，与右 Ctrl 语义一致，适合没有右 Ctrl 的紧凑键盘。松开时激活菜单栏的副作用已被屏蔽，
  AltGr 组合字符不受影响。
- **测试麦克风**：设置页「听写」与引导页「麦克风」一步可实时查看音量（最多 20 秒，不保存任何音频）；引导页可直接
  选择输入设备。
- 托盘菜单 **「复制上一次识别结果」**，随时找回最近一次的文字（只在内存中）。
- **纠错中再按热键可跳过**，立即上屏识别原文。
- 模型下载显示已下载量、速度与剩余时间；**下载完成或失败时弹出托盘通知**。
- 「诊断与帮助」页显示最近 20 次听写的耗时，并可一键「复制诊断信息」（不含识别文本）。
- 录制热键时，若录到 `Ctrl + C`、`Alt + Tab` 等常用快捷键会提醒冲突。
- 浮窗：最后 15 秒倒计时、纠错中提示「再按 X 跳过」、预览尾部淡显、半透明时淡入淡出并允许点击穿透；调整浮窗
  位置或透明度时弹出示例浮窗预览。

### 改进

- **按热键到可以开口更快**：麦克风改在后台打开，浮窗立刻显示灰色「麦克风启动中…」，变红即可说话；按热键时
  不再逐个枚举音频设备。
- **预览更跟嘴**：采集块从 600ms 缩短到 200ms，预览改为事件驱动；松键时中止仍在跑的预览，终稿不必排队。
- **等待时有反馈**：录音中模型仍在加载、识别超过 2 秒的计时、「正在输入…」、纠错后的文本都会显示在浮窗里。
- **不再卡住全局输入**：剪贴板备份移出 UI 线程，键盘钩子移到专用线程。
- **锁屏、睡眠、远程会话切换**时丢弃进行中的录音，恢复后立即重装热键监听；切到 UAC 等安全桌面导致松键丢失时，
  约 0.5 秒内自动结束录音。
- 识别完成时 Alt / Shift / Win 还没松开，会稍等片刻再粘贴，而不是直接降级为只复制。
- 长录音的识别等待时间按时长放宽；识别超时会把已识别的部分复制到剪贴板。
- 「跟随光标」优先跟随文字插入点（Chrome、Electron 等自绘输入框仍跟随鼠标）。
- 开启智能纠错时，开始录音即预先建立连接（不携带密钥与文本），纠错更快返回。
- 启用 ReadyToRun 缩短首次听写前的准备时间；托盘进程不再被 Windows 11 节能模式降速。
- 托盘图标在浅色任务栏上清晰可见；设置窗口适配小屏与高缩放；英文引导文案不再被截断。
- 引导被关闭三次后不再自动弹出（托盘菜单仍可打开）。
- 日志目录改为 `%LOCALAPPDATA%\VoiceTyper\logs`（旧目录不迁移，可手动删除）。

### 修复

- Windows 11 多声道麦克风阵列报「麦克风设备打开失败」；打开失败时会显示真实原因。
- Windows 11 上浮窗只显示一个空白透明框。
- 浮窗不透明度在 40% 以下设置无效；托盘「开机自启」勾选与设置页不一致。
- 设置页「模型目录」总是显示下载目录，而不是模型实际所在位置。
- `build.bat` 因行尾、编码与 PowerShell 执行策略导致打包失败。

## 3.5.1 — 2026-10-03

已在 Windows 真机上确认初步可用，完整模型下载与 SHA256 校验通过（DESIGN §16）；审查修复批次见 DESIGN §17。

### 改进

- **安装包大幅缩小**：改为依赖电脑上已安装的 .NET 10 桌面运行时，不再随包附带 .NET；安装程序会检查运行时并在
  缺少时给出下载地址。新增免安装的便携版。
- **设置窗口重做**为「听写 / 语音模型 / 智能纠错 / 外观与通用 / 诊断与帮助」五页侧栏，统一保存与撤销，关闭后
  保留草稿。
- **模型下载更可靠**：兼容 ModelScope 的特殊响应；403 与 TLS 错误立即切换备用源；「查看下载详情」汇总每个源的
  失败原因。
- 重写 LLM 纠错提示词（与 macOS 共用）。

### 修复

- 首次启动下载完模型后不会自动加载，必须重启应用。
- 开启空闲卸载时，长听写进行中模型可能被卸载导致内容丢失。
- 连续快速听写时，最终可能把识别文本而不是原内容留在剪贴板。
- 模型文件损坏时资源泄漏；退出时偶发释放仍在使用的资源。
- 设置页数值范围与实际校验不一致，打开合法配置却被判定为已修改。
- 快速停止又开始录音时，上一次录音的迟到数据可能混入新录音。
- 日志文件无限增长（现按 2MB 滚动，总量不超过 8MB）。

## 3.5.0 — 2026-09-29

功能对齐 macOS 3.5.0，也是 Windows 版第一次被真实编译、测试与发布。

### 新增

- **首启四步引导**（欢迎 → 麦克风 → 语音模型 → 试一试），最后一步真跑一次听写，明确指出是哪一环出了问题。
- **触发方式**：按住说话，或按一次开始、再按一次结束。
- **右 Ctrl 单独作为热键**；设置页可直接「录制热键」。
- **模型未就绪时按热键会说明原因**（下载中 / 加载中 / 失败），而不是毫无反应。
- **Esc 取消**扩展到识别阶段。
- **浮窗**：实时音量波形、输入设备名、两行预览、没有声音时的提示、按屏幕 DPI 缩放；位置可选底部居中 / 右下角
  / 跟随光标 / 不显示。
- **蓝牙耳机自动改用内置麦克风**；也可在设置中手选设备。
- **可关闭启动预加载**，首次按热键时边录音边加载。
- **模型下载**：大文件四段并行、断点续传、失败自动退避重试。
- **智能纠错默认关闭「深度思考」**，不支持的服务自动回退。
- 托盘菜单手动「检查更新」（不做后台联网）；每次听写输出一行不含文本的耗时日志。

### 修复

- 界面语言保存后重启又变回中文；保存热键会丢失触发方式设置。
- 默认录音设备选错为「通信设备」，蓝牙耳机一录音就切到电话音质。
- 空闲卸载后首次听写可能停不下来；下载失败重试时设置窗口反复抢焦点。
- 静音段预览白耗 CPU。

### 与 macOS 的有意差异

- 「校对中」流光改为文字亮度呼吸；没有「收声」与结果图标弹入动效。
- 没有磨砂背景：WinForms 只能整体调节浮窗透明度。
- 没有系统权限引导：Windows 的「麦克风」一步以能否打开设备为准。
