# VoiceTyper for Windows

**简体中文** · [English](README.en.md)

[← 项目主页](../README.md) · [下载安装包](https://github.com/oyasmi/voice-typer/releases) · [变更记录](CHANGELOG.md) · [开发说明](DEVELOPMENT.md)

VoiceTyper 是一款轻量系统托盘语音输入应用：在任何窗口里按住键盘右侧的 <kbd>Ctrl</kbd> 键说话，松开后文字就会直接写到光标处。语音识别完全在你的电脑本机运行，录音绝不上传。

> [!NOTE]
> **当前状态**：Windows 版采用原生系统托盘与 WinForms 界面，已在 Windows 真机上跑通听写与模型下载；最新细节改进，以及在 arm64 笔记本、长时间运行与多显示器 DPI 缩放下的系统性真机验收仍在进行中。遇到异常欢迎[反馈问题](#反馈问题)。

## 安装与系统要求

| 项目 | 要求 |
| --- | --- |
| **系统** | Windows 10（1809 或更新）或 Windows 11 |
| **处理器架构** | x64（绝大多数电脑）或 arm64（含骁龙 Snapdragon X 笔记本） |
| **运行时依赖** | [.NET 10 桌面运行时（Desktop Runtime）](https://dotnet.microsoft.com/download/dotnet/10.0) |
| **磁盘空间** | 约 300 MB（含应用本体与首次自动下载的语音模型） |
| **网络需求** | 仅首次下载语音模型时需要联网，之后可完全离线使用 |

### 安装步骤

1. **安装 .NET 10 桌面运行时**：打开 [.NET 10 下载页](https://dotnet.microsoft.com/download/dotnet/10.0)，在 **.NET Desktop Runtime** 一栏选择与你电脑一致的架构（通常为 `x64`）。
   - 注意：普通 `.NET Runtime` 或 `.NET 8 / 9` 不能替代；若已安装 `.NET 10 SDK` 则无需重复安装。
2. **下载安装包**：前往 [Releases](https://github.com/oyasmi/voice-typer/releases) 下载：
   - 大多数电脑：`VoiceTyper-<版本>-win-x64-setup.exe`
   - ARM 笔记本：`VoiceTyper-<版本>-win-arm64-setup.exe`
   - 免安装便携版：也可下载对应的 `*-portable.zip`，解压到独立文件夹后直接运行 `VoiceTyper.exe`。
3. **运行安装**：安装程序默认装入当前用户目录，无需管理员权限。若弹出「Windows 已保护你的电脑」SmartScreen 提示，点击 **更多信息 → 仍要运行** 即可（因安装包尚未购买商业代码签名证书，不影响功能）。

## 首次启动

第一次运行会弹出四步引导：**欢迎 → 麦克风 → 语音模型 → 试一试**。

- **确认麦克风**：选择要使用的录音设备，点击「测试麦克风」可查看实时音量条。若无法打开麦克风，请检查 Windows「设置 → 隐私和安全性 → 麦克风」是否允许桌面应用访问麦克风（除此之外无需其他系统授权）。
- **自动准备语音模型**：约 240 MB 的语音模型会在后台自动下载并校验完整性，支持断点续传、失败自动重试与备用源切换。
- **真实试听写**：在引导窗口内亲自完成一次「按住说话、松开出字」，确认热键、麦克风、模型与输入链路全部畅通。之后可随时从右键托盘菜单点击「使用引导...」重新打开。

> **找到托盘图标**：VoiceTyper 运行在任务栏右下角的系统托盘中（Windows 11 默认可能把它收进 `^` 展开面板里，拖到任务栏即可常驻显示）。图标右下角圆点颜色代表当前状态：**红**＝录音中、**黄**＝识别或输入中、**橙**＝模型下载中、**灰**＝加载中或已暂停、**深红**＝发生错误。

## 日常使用

1. 把光标点在需要输入文字的位置。
2. 按住 **右 <kbd>Ctrl</kbd>**：浮窗先短暂显示灰色的「麦克风启动中…」，**变为红色「录音中」后再开口说话**。浮窗会实时显示识别预览，并随着后文语境自动修正前文。
3. 松开右 <kbd>Ctrl</kbd>，带好标点的最终文字直接写入当前窗口。

### 热键贴士

- **不干扰日常快捷键**：只有单独按住右 <kbd>Ctrl</kbd> 时才会听写；按住右 <kbd>Ctrl</kbd> 再按其他键（如右 <kbd>Ctrl</kbd> + <kbd>C</kbd>）依然是普通复制快捷键，当次录音会自动静默作废。
- **键盘没有右 <kbd>Ctrl</kbd>？** 许多新款笔记本把右 <kbd>Ctrl</kbd> 换成了 Copilot 键。可在「设置 → 听写」里一键选用预设的 <kbd>Ctrl</kbd> + <kbd>Tab</kbd>（启用后会接管其他应用的标签页切换），或点击「录制热键」自定义组合键（如 <kbd>Ctrl</kbd> + <kbd>F2</kbd>）。不推荐使用右 <kbd>Alt</kbd>，以免激活应用菜单栏导致输入框失焦。

### 顺手的日常细节

- **随时取消**：录音中或识别中按 <kbd>Esc</kbd> 立即作废，不会写入任何内容。
- **找回历史文字**：右键托盘菜单提供两项找回方式（仅保存在内存中，退出应用即清空）：
  - **复制上一次识别结果**：一键把刚说完的上一条复制到剪贴板；
  - **近期识别历史...**：按从新到旧查看最近 20 条记录（包含中途取消或失败前已识别出的部分文字，并带有「已取消」「部分结果」标记）。可选中单条查看全文并复制，或点击「全部复制（旧到新）」按说话先后顺序换行拼接导出，也支持手动「清空历史」。
- **长段口述与防吞字**：可在设置中把触发方式改为「按一次开始、再按一次结束」。单次最长 120 秒（最后 15 秒显示倒计时，到时自动结束并正常上屏）；短于 0.3 秒的轻触按误触忽略；正常松键后会自动补录约 150ms，减少末尾半个字被截断。
- **中英混说与数字排版**：无需手动切换语言，中英文之间自动加空格（「我用 Python 写代码」），口述数字自动整理为阿拉伯数字。
- **防误输入与密码框保护**：录音途中如果你切换到了其他窗口，结果只会复制到剪贴板，绝不误写进意料之外的窗口；检测到焦点位于密码框时不启动听写，上屏前还会二次复查，受保护时保留在历史记录中供手动复制。
- **托盘快捷菜单**：右键托盘图标即可快速切换识别语言、智能纠错、麦克风策略（自动选择 / 跟随系统默认），或暂停听写、检查更新。

## 设置

所有配置均可在设置窗口中完成，无需手动编辑配置文件。窗口会自动适配高分屏缩放与窄窗口布局，底部固定提供保存与撤销按钮：

| 设置页 | 包含选项 |
| --- | --- |
| **听写** | 热键预设与录制、触发方式（按住 / 按一下切换）、麦克风选择与「测试麦克风」、识别语言（自动 / 中 / 英 / 粤 / 日 / 韩） |
| **语音模型** | 模型状态、下载管理与详情、内存驻留策略 |
| **词汇** | 自定义词汇表（人名、产品名、专业术语）、识别偏向强度与替换预览 |
| **智能纠错** | OpenAI 兼容服务地址、API Key、模型名称与连通性测试 |
| **外观与通用** | 浮窗位置与不透明度（带实时预览）、开机自启、界面语言 |
| **诊断与帮助** | 麦克风状态自检、最近 20 次听写分段耗时、一键复制诊断信息、打开日志与配置目录 |

几个值得留意的选项：

- **热键冲突提醒**：点击「录制热键」自定义组合键时，若录到 <kbd>Ctrl</kbd> + <kbd>C</kbd>、<kbd>Alt</kbd> + <kbd>Tab</kbd> 等系统常用快捷键会主动提醒避让。
- **蓝牙耳机自动保护**：麦克风默认设为「自动」——当系统默认输入和输出同时为蓝牙耳机时，自动改用电脑内置麦克风收音，避免蓝牙耳机切入低音质通话模式；也可固定指定某个麦克风或始终跟随系统默认。
- **内存策略**：默认启动时预加载模型常驻内存，换取按下热键零等待。内存紧张时可关闭预加载，或设置空闲多久后自动释放——下次按热键时会边录音边加载。
- **界面语言**：支持简体中文与 English（重启应用生效），与识别语言互不影响。

### 自定义词汇

经常被认错的人名、产品名、项目代号或行业术语，可以添加到「设置 → 词汇」中（最多 200 条，点击「保存并应用」后从下一次听写生效，全程在本机运行、不联网）：

- **写法**：期望输出的正确写法，例如 `VoiceTyper`、`Claude`、`张三丰`。
- **听起来像**（可选）：常被误认成的同音写法（例如给 `Claude` 填 `克劳德`，多个读法用逗号分隔）。仅大小写、空格或连字符不同的变体（如 `voice typer`、`Voice-Typer`）无需填写，会自动统一为你设定的写法。
- **识别偏向**：提供「关 / 轻 / 标准 / 强」四档（默认「标准」）。档位越高越容易认出词表里的词，但也更可能把发音相近的普通词往词表上靠；发音明显不同的词不会被改。偶遇误改时调低一档即可。
- **从最近结果添加 & 试一试替换**：可直接在最近一次识别文字中框选错字添加进词表；也可在「试一试替换」输入框中打一句话即时查看文本替换效果（声学识别偏向效果请直接开口听写体验）。
- **状态提示**：保存后，`✓` 表示该词同时参与识别偏向与文本替换；`⚠` 表示单字或单个英文片段等情况，仅做文本替换以防误伤日常词。

开启智能纠错时，自定义词汇表也会一并附带给纠错模型参考。

### 智能纠错（可选，默认关闭）

可接入任意兼容 OpenAI 接口的服务（包括 Ollama、LM Studio 等本机离线模型），进一步修正同音错字、口误重复并顺滑标点：

- 开启后**只发送识别出的文字**到你填写的服务地址，音频永远不会发出；为缩短等待时间，按下热键开始录音时会预先建立网络连接（不携带密钥与任何文字）。API Key 使用 Windows DPAPI 加密存储，仅当前系统账户可解密。
- 等待纠错期间，再按一次听写热键即可跳过纠错、直接上屏识别原文（若使用右 <kbd>Ctrl</kbd> 等单修饰键，需单独轻按并松开才触发跳过，右 <kbd>Ctrl</kbd> + <kbd>C</kbd> 等组合键不会误跳过）。
- 纠错超时或出错时会自动回退并写入识别原文。

## 隐私

- 录音仅在内存中实时处理，不落盘、不上传。
- 模型下载完成后即可彻底断网运行；「检查更新」仅在你手动点击时联网。
- 无需登录账号，无使用次数限制。
- 日志与诊断信息绝不记录识别文本或自定义词汇；「上一次识别结果」与最近 20 条识别历史仅存于内存，退出应用即清除。

## 常见问题

### 按下热键没有任何反应？

1. 确认右下角托盘里有 VoiceTyper 图标，且未勾选「暂停听写」。
2. 确认没有其他软件占用同一热键（例如同时开着旧版分体式客户端）。
3. 若当前前台窗口是任务管理器、管理员终端等**以管理员身份运行**的程序，Windows 安全机制可能拦截普通权限程序的热键监听，切回普通窗口即可恢复。

### 浮窗识别成功了，但文字没写进目标窗口？

如果目标窗口是以管理员身份运行的（如管理员 PowerShell / CMD），Windows 的用户界面特权隔离（UIPI）会阻止普通程序向其模拟输入。此时识别好的文字已经放进剪贴板，直接按 <kbd>Ctrl</kbd> + <kbd>V</kbd> 粘贴即可。部分全屏游戏、远程桌面与密码框同样如此。

### 浮窗提示没有检测到声音？

录音时浮窗会显示当前使用的麦克风名称。请确认麦克风未静音、设置中选对了输入设备，并检查 Windows「设置 → 隐私和安全性 → 麦克风」权限；可在 VoiceTyper「设置 → 听写」中点击「测试麦克风」观察音量条排查。

### 模型下载失败？

打开「设置 → 语音模型」点击 **查看下载详情**，查看各下载源的具体报错。若提示 TLS 或证书错误，通常与系统时间不准、网络代理或公司防火墙证书拦截有关；排查后点击「重试下载」，会从已下载位置断点续传。

### 启动时提示缺少 .NET 运行时？

请前往 [.NET 10 下载页](https://dotnet.microsoft.com/download/dotnet/10.0) 安装 **.NET Desktop Runtime 10.0**（注意选择 Desktop Runtime，并匹配电脑的 `x64` 或 `arm64` 架构）。

### 可以和旧版「分体式客户端」同时安装吗？

可以共存，但建议只运行其中一个以免争抢热键。首次安装一体化版本时，会自动继承旧版的热键（旧版默认为 <kbd>Ctrl</kbd> + <kbd>F2</kbd>）与浮窗透明度。

### 已知限制

- 当前仅使用 CPU 推理；
- 固定使用 SenseVoice-Small 模型，不支持切换其他语音模型；
- 左 <kbd>Alt</kbd>、<kbd>Win</kbd>、<kbd>Shift</kbd> 不能单独作为听写热键；
- 仅支持本机离线识别，不支持连接远程识别服务端（如有远程 GPU 服务端或多模型需求，请使用[客户端—服务端版本](../client-server/README.md)）。

## 卸载

在 Windows「设置 → 应用 → 已安装的应用」中卸载 VoiceTyper（或使用开始菜单中的「卸载 VoiceTyper」）。卸载程序默认保留你的配置与已下载的语音模型；如需彻底清除所有数据，请手动删除以下两个文件夹：

- `%APPDATA%\VoiceTyper\`
- `%LOCALAPPDATA%\VoiceTyper\`

## 反馈问题

欢迎在 [GitHub Issues](https://github.com/oyasmi/voice-typer/issues) 中反馈问题，并说明现象、Windows 版本与处理器架构（x64 / arm64）。建议附上诊断信息：打开「设置 → 诊断与帮助」，可一键 **复制诊断信息** 或打开日志目录（`%LOCALAPPDATA%\VoiceTyper\logs\`）——诊断信息与日志均不包含任何识别文本。
