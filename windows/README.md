# VoiceTyper for Windows

**简体中文** | [English](README.en.md)

[← 项目主页](../README.md) · [下载](https://github.com/oyasmi/voice-typer/releases) · [变更记录](CHANGELOG.md) · [开发说明](DEVELOPMENT.md)

VoiceTyper 是一个托盘应用：在任何应用里按住键盘右侧的 `Ctrl` 键说话，松开后文字就写到光标处。语音识别
完全在你的电脑上完成，录音不会上传。

> **当前状态**：Windows 版功能与 macOS 版对等，已在 Windows 真机上跑通听写与模型下载，但系统性
> 的真机验收（尤其是 arm64 设备、长时间运行和多显示器 DPI）还在进行中。遇到问题欢迎
> [反馈](#反馈问题)。

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10（1809 或更新）或 Windows 11 |
| 架构 | x64 或 arm64（含 Snapdragon X 笔记本） |
| 运行时 | [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)（需单独安装） |
| 磁盘 | 约 300MB（应用 + 首次下载的语音模型） |
| 网络 | 只在首次下载模型时需要 |

## 安装

1. 安装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)：选择 **Desktop Runtime**，
   架构与电脑一致（大多数电脑是 x64）。普通 .NET Runtime 或 .NET 8/9 不能代替；装过 .NET 10 SDK 则不必重复安装。
2. 从 [Releases](https://github.com/oyasmi/voice-typer/releases) 下载安装包：
   `VoiceTyper-<版本>-win-x64-setup.exe`（大多数电脑）或 `VoiceTyper-<版本>-win-arm64-setup.exe`（ARM 笔记本）。
3. 运行安装包。它安装到当前用户目录，不需要管理员权限。
4. 如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

> 安装包没有代码签名，所以会触发 SmartScreen 提示，这不影响使用。缺少 .NET 运行时时，安装程序会提示下载地址。
> 不想安装的话，也可以下载便携版 `*-portable.zip`，解压后运行 `VoiceTyper.exe`。

## 首次启动

应用会打开一个四步引导：**欢迎 → 麦克风 → 语音模型 → 试一试**。

- **麦克风**：可以直接选择输入设备，点「测试麦克风」查看实时音量。如果打不开麦克风，检查「设置 → 隐私和
  安全性 → 麦克风」是否允许桌面应用使用。Windows 版不需要其他系统授权。
- **语音模型**（约 240MB）首次启动就会在后台自动下载并校验，支持断点续传，失败会自动重试或换用备用下载源。
- **试一试**：在引导窗口里真正完成一次听写。只有这一步成功，才说明热键、麦克风、识别和输入整条链路都已
  就绪；哪一环有问题，引导会直接指出。之后可以从托盘菜单「使用引导...」重新打开。

VoiceTyper 的图标在任务栏右下角的托盘里。Windows 11 默认会把它收进「^」里，可以把它拖出来常驻。

## 日常使用

1. 把光标放在要输入的位置。
2. 按住**右 Ctrl**。浮窗先显示灰色的「麦克风启动中…」，**变成红色「录音中」后再开口**。浮窗会实时显示
   识别结果，并随着你继续说自动修正前文。
3. 松开右 Ctrl，最终文字（带标点）写入当前应用。

右 Ctrl 只有单独按住时才会开始听写；按住它再按别的键（如右 Ctrl + C）仍是普通快捷键，这次录音会被静默丢弃。
键盘没有右 Ctrl（不少新笔记本把它换成了 Copilot 键）的话，可以在设置里一键改用次选的 `Ctrl + Tab`，或自行录制组合键。
`Ctrl + Tab` 设为听写热键后，会替代其他应用原本的切换标签页功能。右 Alt 可能激活菜单栏并使输入框失焦，已不再推荐。

几个有用的细节：

- **取消**：录音中或识别中按 `Esc`，什么都不会写入。
- **找回结果**：托盘菜单「复制上一次识别结果」保留原功能；新增「近期识别历史...」，按新到旧查看最近 20 条最终文字
  （包含最后一条），选择记录可查看全文、单条复制。「全部复制（旧到新）」按说话顺序用换行拼接当前保留的所有记录。
  历史只保存在内存里，退出即清除；正在听写时需等当前这段结束再复制。
- **长段口述**：在设置里把触发方式改为「按一次开始、再按一次结束」，不用一直按着。
- **时长**：单次最长 120 秒，最后 15 秒会显示倒计时，到时自动结束并正常上屏；短于 0.3 秒的按键视为误触。
- **中英混说**：不用切换，中英文之间会自动加空格（「我用 Python 写代码」）。
- **防止误输入**：如果录音期间你切换到了别的窗口，结果只会复制到剪贴板，不会写进意料之外的地方。

托盘图标右下角的小圆点表示当前状态：红色是录音中，黄色是识别或输入中，橙色是模型下载中，灰色是加载中或
已暂停，深红色是出错。右键托盘图标可以打开设置、暂停听写、检查更新等。

## 设置

所有选项都在设置窗口里，不需要编辑配置文件。

窗口会随屏幕缩放和可用空间调整；缩窄时，设置项会改为上下排列，内容可纵向滚动，底部始终提供保存与撤销。
麦克风、服务地址和模型名称使用整行输入框，方便查看较长的内容。

| 页面 | 内容 |
| --- | --- |
| 听写 | 热键、触发方式、麦克风与「测试麦克风」、识别语言（自动 / 中 / 英 / 粤 / 日 / 韩） |
| 语音模型 | 模型状态与下载、内存策略 |
| 词汇 | 自定义词汇（人名、产品名、术语）与识别偏向强度 |
| 智能纠错 | 服务地址、API Key、模型名称、测试 |
| 外观与通用 | 浮窗位置与透明度、开机自启、界面语言 |
| 诊断与帮助 | 麦克风检测、最近 20 次听写的耗时、日志与配置目录 |

- **热键**：首推默认的**右 Ctrl**，次推 **Ctrl + Tab**，设置页均有快捷设置按钮；也可点「录制热键」直接按下想用的组合（如
  `Ctrl + F2`）；录到 `Ctrl + C`、`Alt + Tab` 等常用快捷键时会提醒冲突。
- **麦克风**：默认「自动」——默认输入和输出都是蓝牙耳机时，改用电脑内置麦克风，避免耳机切到通话模式导致
  音质变差。也可以固定使用某个设备或跟随系统默认。
- **内存**：默认启动时加载模型并常驻，按下热键零等待。内存紧张时可以关闭预加载，或设置空闲多久后自动释放；
  下次按热键会边录音边加载。
- **界面语言**：中文或英文，重启应用后生效。界面语言与识别语言互不影响。

### 自定义词汇

总被认错的人名、产品名、项目代号和术语，可以在「设置 → 词汇」里列出来，全部在本机完成、不联网：

- **写法**：正确的写法，例如 `张三丰`、`VoiceTyper`、`Claude`。
- **听起来像**（可选）：常被认成的样子，例如给 `Claude` 填 `克劳德`，多个用逗号分隔。`voice typer`、`Voice-Typer`
  这类空格、连字符、大小写的变体不用写，会自动统一成你写的样子。
- **识别偏向**：关 / 轻 / 标准 / 强，默认「标准」。越强越容易认出表里的词，也越可能把读音相近的普通词认成它；
  发音明显不同的词不会被改。觉得被误改时调低一档。
- **从最近结果添加**：看到一次认错，就在最近的识别结果里选中认错的那几个字，填上正确写法即可。
- **试一试替换**：输入一句话，立刻看到替换后的样子（只演示替换，识别偏向请直接听写体验）。
- **状态列**：✓ 表示已参与识别偏向；⚠ 表示只有一个字（或一个英文片段）等情况，这类词只做替换、不参与识别偏向；
  刚添加的词保存后才会检查。

改完点「保存并应用」，下一次听写生效。最多 200 条。不配置词汇时识别结果与以前完全一样。开启智能纠错时，词表也会
一并提供给纠错服务。

### 智能纠错（可选，默认关闭）

接入任意 OpenAI 兼容服务（包括本机运行的模型），修正同音字、口误和标点。开启后只有**识别出的文字**会发给
你配置的服务，音频永远不会发送。为了减少等待，开始录音时会先与服务建立连接（不携带密钥和任何文字）。
API Key 用 Windows DPAPI 加密保存，只有当前用户能解密。

纠错期间再按一次热键可以跳过、直接上屏原文；纠错失败时会自动使用原文。

## 隐私

- 录音只在内存中处理，不写入磁盘，不上传到任何地方。
- 模型下载完成后可以完全断网使用；「检查更新」只在你手动点击时联网。
- 无需注册账号，没有使用次数限制。
- 日志不记录识别文本，也不记录自定义词汇；「上一次识别结果」和最近 20 条识别历史只在内存中，退出即清除。

## 常见问题

### 按热键没有反应？

确认托盘里有 VoiceTyper 图标、没有处于「暂停听写」状态，且没有其他程序占用同一个热键（比如同时运行着旧版
分体式客户端）。任务管理器等以管理员身份运行的窗口在前台时，系统可能拦截热键，切到普通窗口再试。

### 识别成功了，但文字没写进去？

如果目标窗口以管理员身份运行（如管理员终端），Windows 会阻止普通程序向它输入文字。此时结果已在剪贴板里，
按 `Ctrl + V` 即可。部分游戏、远程桌面和密码框也会拒绝模拟输入。

### 浮窗提示没有检测到声音？

浮窗录音时会显示当前使用的麦克风名称。确认麦克风没有静音、设置里选对了设备，并检查 Windows 的麦克风隐私
设置。可以在「设置 → 听写」里点「测试麦克风」排查。

### 模型下载失败？

到「设置 → 语音模型」点「查看下载详情」，那里会列出每个下载源的失败原因。TLS 或证书错误通常与系统时间、
代理或公司网络有关。处理后点「重试下载」，会从中断处继续。

### 提示缺少 .NET 运行时？

安装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，注意选 **Desktop Runtime**
和与电脑一致的架构。

### 能和旧版「分体式客户端」一起装吗？

可以共存，但建议只保留一个。从旧版迁移时，热键（旧版默认 `Ctrl + F2`）与浮窗透明度会自动继承；两者用同一个
热键时，同时运行会抢热键。

### 已知限制

只使用 CPU 推理；只使用 SenseVoice-Small 模型，不支持更换模型；左 Alt、Win、Shift 不能单独作为热键；
识别始终在本机运行，不支持远程服务端（有这类需求请使用[客户端—服务端版本](../client-server/README.md)）。

## 卸载

在「设置 → 应用」中卸载 VoiceTyper，或使用开始菜单里的「卸载 VoiceTyper」。卸载不会删除配置和模型，
如需彻底清除，手动删除 `%APPDATA%\VoiceTyper\` 与 `%LOCALAPPDATA%\VoiceTyper\`。

## 反馈问题

请在 [Issues](https://github.com/oyasmi/voice-typer/issues) 中描述现象、Windows 版本与电脑架构。附上诊断信息会很有
帮助：「设置 → 诊断与帮助」里可以一键复制诊断信息、打开日志目录（`%LOCALAPPDATA%\VoiceTyper\logs\`）。
诊断信息与日志都不包含识别文本。
